# 🎬 Movie Ticket Booking System

A full-stack Movie Ticket Booking Web Application built using the MERN Stack. This platform allows users to browse movies, select seats, and book tickets online with secure payment integration.

---

## 🌐 Live Demo

🚀 **Live Project:**  
👉 https://cinebooker-one.vercel.app/

---

## 🚀 Features

### 👤 User Features
- 🎥 Browse movies with ratings, cast, and trailers
- 🕒 Select show timings
- 💺 Interactive seat selection system
- ❤️ Add movies to favourites
- ⭐ View movie ratings and details
- 🎟️ Book tickets after successful payment
- 📧 Receive booking confirmation via email

### 💳 Payment Integration
- Secure online payments using **Stripe**
- Booking confirmed only after successful payment

### 🔐 Authentication
- JWT-based authentication system
- Secure login and signup functionality

### 🛠️ Admin Panel
- Separate Admin Dashboard
- ➕ Add movies and shows
- 📃 Manage and list all shows
- 🎬 Control movie scheduling

---

## 💡 Unique Features

- Separate admin panel for managing shows and movies
- Stripe payment integration with confirmation flow
- Email notification after booking
- JWT authentication for secure access
- Clean and user-friendly UI
